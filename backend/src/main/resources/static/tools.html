Demo tools

Admin actions for demos and data maintenance.

Replay haze episode

Runs the Sept 2026 haze readings through normal detection. The first sustained breach becomes a NEW event, tagged as a replay. Only one replay event can be open at a time: dismiss it to replay again.

Backfill PM2.5 readings

Loads historical readings from data.gov.sg for every region (Singapore dates, both inclusive, max 31 days per run). Safe to rerun: existing readings are skipped.
